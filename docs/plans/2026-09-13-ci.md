# CI and Releases Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every pull request runs the checks in GitHub Actions, a release is a pull request a bot keeps open from the Conventional Commits, and merging it publishes `cluide` to npm with trusted publishing once the repository is public.

**Architecture:** Three workflows (`ci.yml`, `release.yml`, `audit.yml`) share one composite setup action that installs the pinned Bun with a frozen lockfile. release-please runs in manifest mode with pull-request-title notes. The publish job is gated by the repository variable `NPM_PUBLISH`, reruns every check on the tagged commit, builds, publishes over OIDC and attaches the tarball. A `scripts/check-docs.ts` enforces links, status lines and the forbidden-names rule read from a repository variable.

**Tech Stack:** GitHub Actions on `ubuntu-latest`, Bun 1.3.14, release-please 17 (action v5), npm 11 for the publish step, Dependabot.

**Spec:** `docs/spec/ci/README.md` (binding), with `docs/spec/foundation/dev-and-build.md` and `security.md` rows, and the ADR `docs/adr/2026-09-13-adopt-commit-driven-releases.md`.

## Global Constraints

- Bun `1.3.14`, declared once as `"packageManager": "bun@1.3.14"` in `package.json` and read by `setup-bun`.
- Every action pinned to a commit SHA with the version in a trailing comment: `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1`, `oven-sh/setup-bun@0c5077e51419868618aeaa5fe8019c62421857d6 # v2.2.0`, `actions/cache@55cc8345863c7cc4c66a329aec7e433d2d1c52a9 # v6.1.0`, `actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1`, `googleapis/release-please-action@45996ed1f6d02564a971a2fa1b5860e934307cf7 # v5.0.0`.
- Top-level `permissions: contents: read` in every workflow; a job adds only what it needs.
- `bun install --frozen-lockfile` everywhere in CI.
- No secret anywhere. Publishing authenticates with OIDC (`id-token: write`); uploads use the job token.
- Runtime dependency of the package: `ajv` only. The package has no `private` flag.
- Copy rules of the repo hold for the README and the workflow names: no exclamation marks, no other project's or company's name.
- Git: Conventional Commits without scope, the `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` trailer, ask before every commit; one commit per task.
- Plan discipline: this file is deleted in Task 4; anything durable it establishes moves to the spec first.

- [ ] **Step 2: `scripts/check-docs.ts`**

```ts
import { existsSync, readdirSync, readFileSync, statSync } from "node:fs";
import { dirname, join, relative, resolve } from "node:path";

const STATUS = /^Status: (Draft|Stable) · (Built|Partial|Planned) · \d{4}-\d{2}-\d{2} · .+$/;
const LINK = /\]\((\.{1,2}\/[^)#\s]+)/g;
const TEXT = /\.(md|ts|tsx|json|css|yml|yaml|html|svg|txt)$/;
const SKIP = ["node_modules", "dist", ".git", "e2e/renders", "docs/spec/ui/design"];

function* walk(root: string, dir = root): Generator<string> {
  for (const name of readdirSync(dir).sort()) {
    const path = join(dir, name);
    const rel = relative(root, path);
    if (SKIP.some((s) => rel === s || rel.startsWith(`${s}/`))) continue;
    if (statSync(path).isDirectory()) yield* walk(root, path);
    else yield path;
  }
}

// Every violation as "<relative path>:<line> <message>", sorted, so CI output is stable.
export function checkDocs(root: string, forbidden: string[]): string[] {
  const out: string[] = [];
  const names = forbidden.map((n) => n.trim()).filter(Boolean).map((n) => new RegExp(`\\b${n.replace(/[.*+?^${}()|[\]\\]/g, "\\$&")}\\b`, "i"));
  for (const path of walk(root)) {
    const rel = relative(root, path);
    if (!TEXT.test(rel)) continue;
    const lines = readFileSync(path, "utf8").split("\n");
    if (rel.endsWith(".md")) {
      // Links inside fenced code blocks are examples, not references.
      let fenced = false;
      lines.forEach((line, i) => {
        if (/^\s*(```|~~~)/.test(line)) fenced = !fenced;
        if (fenced) return;
        for (const m of line.matchAll(LINK)) {
          if (!existsSync(resolve(dirname(path), m[1]))) out.push(`${rel}:${i + 1} broken link: ${m[1]}`);
        }
      });
      if (rel.startsWith("docs/spec/") && rel !== "docs/spec/README.md" && rel.endsWith(".md") && !rel.endsWith("design-brief.md")) {
        if (!STATUS.test(lines[2] ?? "")) out.push(`${rel}:3 status line must read \`Status: <Draft|Stable> · <Built|Partial|Planned> · <date> · <sentence>\``);
      }
    }
    lines.forEach((line, i) => {
      for (const [k, re] of names.entries()) if (re.test(line)) out.push(`${rel}:${i + 1} forbidden name: ${forbidden[k].trim().toLowerCase()}`);
    });
  }
  return out.sort();
}

if (import.meta.main) {
  const names = (process.env.FORBIDDEN_NAMES ?? "").split(",").map((n) => n.trim()).filter(Boolean);
  if (names.length === 0) console.log("FORBIDDEN_NAMES is not set; the names check is skipped");
  const violations = checkDocs(process.cwd(), names);
  for (const v of violations) console.log(v);
  console.log(violations.length === 0 ? "docs ok" : `${violations.length} violation(s)`);
  process.exit(violations.length === 0 ? 0 : 1);
}
```

Only `docs/**` and `CLAUDE.md` matter for links and status lines; the names check covers every text file in the tree. If the test's expected order differs from the sort, fix the test's order to the sorted one, not the sort.

Run: `bun test scripts/check-docs.test.ts` → 2 pass. `bun run check-docs` on the repo → `docs ok`. `FORBIDDEN_NAMES="Acme Corp" bun run check-docs` → `docs ok` as well.

- [ ] **Step 2: `release.yml`**

```yaml
name: Release

on:
  push:
    branches: [main]
  workflow_dispatch:
    inputs:
      tag:
        description: An existing release tag to publish, for example v0.1.0
        required: true
        type: string

permissions:
  contents: read

jobs:
  release:
    name: Release pull request
    if: github.event_name == 'push'
    runs-on: ubuntu-latest
    timeout-minutes: 5
    permissions:
      contents: write
      pull-requests: write
    outputs:
      created: ${{ steps.rp.outputs.release_created }}
      tag: ${{ steps.rp.outputs.tag_name }}
    steps:
      - id: rp
        uses: googleapis/release-please-action@45996ed1f6d02564a971a2fa1b5860e934307cf7 # v5.0.0
        with:
          config-file: .release-please-config.json
          manifest-file: .release-please-manifest.json
      - if: steps.rp.outputs.release_created == 'true' && vars.NPM_PUBLISH != 'true'
        run: echo "::notice::${{ steps.rp.outputs.tag_name }} is released on GitHub; npm publishing is off until the repository variable NPM_PUBLISH is true"

  publish:
    name: Publish
    needs: [release]
    if: always() && (github.event_name == 'workflow_dispatch' || (needs.release.outputs.created == 'true' && vars.NPM_PUBLISH == 'true'))
    runs-on: ubuntu-latest
    timeout-minutes: 20
    permissions:
      contents: write
      id-token: write
    env:
      TAG: ${{ inputs.tag || needs.release.outputs.tag }}
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
